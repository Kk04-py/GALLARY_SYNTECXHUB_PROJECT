📌 ClickStack – Modern Image Gallery Web App

ClickStack is a modern and responsive image gallery web application built using HTML, CSS, and JavaScript. It showcases beautifully arranged images in a clean masonry/grid layout with category-based filtering and interactive UI elements.

The project focuses on creating an aesthetic and user-friendly gallery experience while practicing front-end web development concepts like responsive design, DOM manipulation, event handling, and dynamic filtering.

✨ Features
Responsive masonry-style gallery layout
Category filter buttons
Smooth hover animations and transitions
Fully responsive for mobile, tablet, and desktop
Clean dark-themed modern UI
Interactive image cards using JavaScript
Lightweight and beginner-friendly project
🛠️ Technologies Used
HTML5
CSS3
JavaScript (Vanilla JS)
🎯 Purpose

This project was created to improve front-end development skills and gain hands-on experience in designing dynamic and visually appealing web interfaces.
